# 🏡 Africok Real Estate Website

Africok is a real estate website showcasing properties, contact details, and services.  
The project is built with **HTML, CSS, and JavaScript** as a lightweight and responsive static site.

---

## ✨ Features
- 🏘️ Property listings page
- 📄 About page
- 📞 Contact page
- 📧 Email integration (via `email.js`)
- 🎨 Styled with CSS for a clean and modern design
- ⚡ Fast and lightweight (no frameworks required)

---

## 🚀 Demo
Live Site: [Africok on Vercel](https://africok.vercel.app)

## 💻 Running Locally
You don’t need Node.js to run this project since it’s a static site.

1. Clone the repository:
   ```bash
   git clone https://github.com/OketchManu/Africok.git
   cd Africok

2. Open index.html in your browser.
Or serve it locally with Node.js (optional):

npx serve .
